# 题库格式 v1

题库由版本化 JSON 和便于阅读的离线 HTML 组成，使用标准 ZIP 打包。导出的 ZIP 解压后双击 `index.html` 即可查看；导入不执行 HTML 或其他脚本。

## 文件布局

```text
学习题库.zip
├─ index.html                 # 离线目录
├─ style.css                  # 离线页面样式
├─ question-bank.json         # 可重新导入的完整数据
├─ FORMAT.txt                 # 随包格式说明
└─ 001 专业课考试/
   └─ 001 药学知识测试/
      └─ index.html            # 题目、选项与答案
```

目录名中的序号用于避免重名，特殊路径字符会被替换。目录只是方便阅读，导入匹配不依赖目录或测试名称。

## JSON 示例

保存为任意名称的 UTF-8 `.json` 文件，或放入 ZIP 中并命名为 `question-bank.json`：

```json
{
  "schema": "sclpa-question-bank",
  "version": 1,
  "questions": [
    {
      "section": "专业课考试",
      "exam": "药学知识测试",
      "title": "这里填写完整题干",
      "type": "single",
      "options": [
        {
          "label": "A",
          "text": "第一个选项"
        },
        {
          "label": "B",
          "text": "第二个选项"
        }
      ],
      "answer": [
        "B"
      ],
      "status": "confirmed"
    }
  ]
}
```

| 字段 | 含义 |
| --- | --- |
| `schema` / `version` | 固定为 `sclpa-question-bank` / `1` |
| `questions` | 题目数组，最多 5000 题 |
| `section` / `exam` | 板块和测试名称；可省略，分别显示“导入题库”“未命名测试” |
| `title` | 完整题干，不使用图片或 HTML；题号前缀会归一化 |
| `type` | `single` 单选、`multiple` 多选、`unknown` 未标明 |
| `options` | 完整选项数组；每项包含唯一的 A–Z 标签 `label` 和选项内容 `text` |
| `answer` | 答案标签数组，如 `["B"]` 或 `["A", "C"]` |
| `status` | `confirmed` 已有答案、`unresolved` 未得出、`conflict` 答案冲突 |
| `source` | 导出时为 `platform` 或 `import`，导入时统一按用户提供的答案处理 |

未得出的题使用 `"answer": []`、`"status": "unresolved"`。不能把 AI 尚未确认的猜测标为正确答案；导入提供的答案在预览中会单独标注来源。单选题只能提供一个答案，所有答案标签必须存在于完整选项中。

## 匹配与合并

- 匹配完整题干与完整选项集合，归一化全半角与多余空白；不依赖板块、测试名称或选项字母排序，不进行模糊匹配。
- 选项顺序改变时按选项内容重新映射字母；选项内容重复或不完整时不自动使用。
- 不同目录下的同一题也可匹配。导入答案互相冲突时不自动选择，交给 AI；平台逐题确认的答案优先。
- 平台确认某个答案错误时，该答案从本地可用候选中移除；总分及格不能证明每一题都正确。
- 重复导入合并题目，未得出的记录不会覆盖已有确认答案。格式无效、超限或同步存储失败时不覆盖原题库。

## 限制

JSON 最大 8 MiB，ZIP 最大 32 MiB，最多 5000 题；每题 2–26 个选项，题干和单个选项最多 4000 字符。标准 ZIP 存储模式和 Deflate 均受支持；不支持加密、多卷或 ZIP64。浏览器缺少 Deflate 解压支持时，可先解压后导入 JSON。

自动保存默认关闭，首次使用会显示说明。记录仅保存在当前脚本管理器中；导出不包含账号、密钥、请求头或浏览记录。题目正文由用户自行保管。
