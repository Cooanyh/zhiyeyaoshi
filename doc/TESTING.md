# 回归测试

测试对象是主脚本。夹具中的题目、课程、通知和配置均为合成数据；测试不会登录学习账号、提交真实考试或请求真实 AI。

## 执行

使用 Node.js 20 或更新版本，安装开发依赖和 Chromium：

```powershell
npm ci --ignore-scripts
npx playwright install chromium
$env:npm_config_script_shell = 'pwsh'
npm test
```

可通过 `BROWSER_EXECUTABLE` 指定隔离测试所用的浏览器可执行文件。测试默认创建临时浏览器配置，不连接个人配置。`PLAYWRIGHT_MODULE_PATH` 可指定已有的 Playwright 模块位置；不设置时使用项目依赖。

资源观察默认 30 秒，可在 PowerShell 中设置 `$env:SOAK_SECONDS = '300'`，再执行 `npm test`。观察前半段运行服务，后半段暂停服务。

## 覆盖

| 文件 | 检查内容 |
| --- | --- |
| `exam-route.cjs` | 全能托管同路由切换、累计确认错答与未确认作答、组合归一化、0–3 次边界、暂停和离开后的迟到纠错 |
| `media-logic.cjs` | 视频有限恢复、跳过与暂停、完成确认、真实解码后的遮罩恢复、保留验证码和媒体错误、隔离窗口的文章计时拦截 |
| `notifications.cjs` | 测试通知回执消失、确认关闭、旧定时器隔离、通知标签、去重、明确失败/拒绝/超时及回退 |
| `phase-flow.cjs` | 合成平台的公需视频→文章→两类空考试列表完整推进、文章确认与返回、结束释放资源 |
| `browser-runtime.cjs` | 真 DOM 与原生媒体属性、重复注入、事件合并、iframe/Shadow DOM 清理、2250 个视频生命周期、堆回收、文章倍率/冻结、无效答案拦截、即时配置、窄屏面板及长期任务数量 |

JS 堆测量使用垃圾回收后的 `JSHeapUsedSize`，不等于浏览器总内存。主线程任务时间不等于整个浏览器或系统的 CPU 使用率。压力检查用于发现持续增长，不能证明任何设备永远不会内存不足。

## 原生后台检查

`native-background.cjs` 是单独的可选检查。必须先启动自己创建的隔离浏览器，核对其独立 `--user-data-dir` 和启动参数；不得连接默认/个人 Chrome，不得使用含 `--force-device-scale-factor=2.0` 的实例。仅对该隔离实例设置 `TEST_CDP_URL`，执行 `npm run test:background`。

该检查使用原生最小化状态和 CDP，断言 `document.hidden`，不使用 Playwright 的标签可见性接管。夹具仍是合成平台；两类考试为空，不计为真实考试通过。测试结束清空夹具页，不关闭或删除浏览器配置。

真实管理器桥接、平台接口保存、AI 答案正确性及操作系统横幅/声音需要另外验证。原生后台检查未执行时，应明确记录，不能用 headless 结果代替。

## 1.4.0 发布检查（2026-10-08）

环境：Node.js 22.21.0、Playwright 1.62.1、隔离 headless Edge 154.0.4258.62。

- 全部六项自动回归入口（语法检查及五个默认回归文件）通过；最后重跑完整组合，包含独立脚本窗口、分数倍率和越界倍率归一化、迟到纠错、窄屏面板以及不执行 AI 输出中的 HTML。
- 2250 个视频生命周期、22500 次媒体事件、12 轮 iframe/Shadow DOM 挂载移除、30 次 AI 面板重建通过；回收后的压力测试 JS 堆增量约 0.08 MiB。
- 资源优化阶段的 300 秒运行/暂停观察通过：待调度任务稳定为 1 个，暂停后媒体/守护/观察器计数归零，回收后 JS 堆增量约 0.01 MiB。
- 最终完整组合的 30 秒观察通过：JS 堆增量约 0.00 MiB，主线程任务累计约 0.091 秒，无未处理页面错误。这不是浏览器全进程 CPU 或总内存测量。
- 合成全能流程进入文章一次、确认后返回一次，推进两类空考试阶段并释放资源；没有计为真实考试通过。
- 本轮未执行新的原生最小化后台检查：启动隔离原生 Edge 的操作被自动审批拒绝，仅返回 blocked by policy。未绕过该拒绝或接管个人浏览器。
- 操作系统真实通知、实际脚本管理器桥接、真实平台保存及真实 AI 服务本轮未作完整端到端验证；金航联源码仅做语法检查，不计入主脚本回归覆盖。
